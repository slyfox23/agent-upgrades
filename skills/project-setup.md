# Skill: Project Setup

Use this skill for bootstrapping a project, creating standard folders, and establishing maintainable conventions.

## Prompt

Set up the project with the least complexity needed to support the stated goal. Prefer obvious project conventions, clear documentation, and reproducible configuration. Keep setup minimal but complete enough to build and validate the work.

## Output expectations

- Created or updated project structure
- Key configuration files
- Brief explanation of conventions used
- Validation steps if applicable
