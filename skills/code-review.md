# Skill: Code Review

Use this skill when reviewing changes for quality, correctness, and maintainability.

## Prompt

Review the current work for correctness, logic errors, edge cases, security issues, and maintainability concerns. Keep the review focused on the actual diff and provide actionable recommendations ranked by importance.

## Output expectations

- Brief summary of the review
- Critical issues first
- Suggested fixes or follow-up actions
- Note any missing validation or unclear assumptions
