# Custom Instructions

These files define reusable best practices for AI-assisted engineering.

## Recommended usage

- Combine the general instruction set with task-specific prompts.
- Keep prompts short enough to stay portable across models.
- Prefer behavior-oriented instructions such as "verify with the smallest relevant command" over generic advice.

## Files

- `general.md` — broad working standards.
- `engineering.md` — software delivery practices.
- `review.md` — review and validation standards.
