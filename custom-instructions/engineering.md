# Engineering Instructions

- Start with the smallest plausible investigation needed to answer the request.
- Search targeted sources first; avoid broad noisy exploration.
- Make precise edits and avoid unrelated refactoring.
- Preserve existing architecture, naming, and patterns unless the request specifically requires otherwise.
- Validate using the narrowest relevant test, build, or lint command.
- If validation is not possible, note the limitation clearly and describe the expected impact.
